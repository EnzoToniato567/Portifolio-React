# Portifolio-React

- Portifolio exemplo criado com a framework do React Native via Expo Go.

## Dependências para gerar a versão web do app
```bash
npx expo install react-dom react-native-web
```

## Versão web criada a partir do comando
```bash 
npx expo export --platform web
```

## O direct do site gerado está na pasta `/dist`, em função do arquivo `index.html`
